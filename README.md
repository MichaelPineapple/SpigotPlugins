# Spigot 1.21 Plugins

A collection of plugins for use in Spigot 1.21 Minecraft servers. 

And just for fun, they are organized into "Albums" based on the general time period in which they were developed. I typically make these in big batches all at once so for me it makese sense to organize them this way.
